### RL-13: How are CIF freight, insurance and buyer-supplied materials treated in customs value?
- **Date:** 2026-10-10

- **Date:** 2026-10-10

## 5. Extraction Options Assessed (no tools installed)

| Option | Strengths | Weaknesses on these documents |
|---|---|---|
| A. Local OCR (e.g. Tesseract) | Free, offline | Plain text only; 🔶 likely weak on overlapping stamps, handwriting and tables; still needs field parsing |
| B. Cloud document OCR (AWS Textract, Google Document AI, Azure Document Intelligence) | Table and form detection | Cloud account and keys; cost; still needs mapping to our fields |
| C. AI vision model with structured output | Handles layout, stamps, handwriting and tables in one step; adapts to new layouts | API key and cost; can return wrong values that look plausible → requires source evidence, confidence, cross-checks and human confirmation |
| D. PDF text layer | Exact, deterministic, free | ✅ Works for the invoice; ✅ verified to return nothing for the PL and B/L |

Direction going into Phase 4: a hybrid of D and C, followed by a deterministic validation layer.
